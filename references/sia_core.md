# SIA 核心检查点（知识诊断自带引擎 · L1 逻辑自洽层）

> 本文件是 `insigoo-sag-architect` 能力三「基于 SIA 标准诊断组织知识」的**自带 L1 引擎**，使本技能在无 `insigoo-sia` 外部技能时也能跑通组织知识体检。
> 本文件对齐 **insigoo-sia v1.2.0（MIT，开源）** 的 L1 逻辑自洽层；完整框架以 `insigoo-sia`（github.com/ericyueric）为准。
> 适用边界：发展性评估工具，**不是审计工具**；不替代资助决策的人工尽调。
> **本文件仅含 L1（逻辑自洽体检）。指标量化定级（L2）与价值核算（L3）属高阶层，不在本技能内联范围。**

---

## 一、7 条评估原则（贯穿 L1）

1. **受益方中心** — 从受益方视角评估，而非资助方/执行方。
2. **逻辑自洽** — 目标→方法→行动必须咬合，不能有断链。
3. **证据为本** — 每项成果声明需有证据或合理推论支撑。
4. **适度量化** — 量化是工具非唯一，叙事证据同样有价值。
5. **诚实归因** — 不夸大贡献，区分"贡献"与"归因"。
6. **透明可复现** — 方法、数据来源、假设须公开披露。
7. **持续改进** — 评估是学习工具而非审判工具。

---

## 二、三种评估模式

| 模式 | 适用场景 | 输出 |
|------|---------|------|
| **快速自检** | 申报前/筹款前快速排查、初筛 | 10 项快检清单 + 三大风险提示 |
| **完整体检**（默认） | 项目设计纠偏、中期复盘、立项论证 | 完整体检报告（五步流程） |
| **批量评审** | 基金会/平台方筛选多份项目申请 | 统一评分卡 + 横向对比表 + 筛选分档 |

模式切换规则：
- 用户说"快速看看/帮我自检/明天要交" → 快速自检模式
- 用户一次提供多份项目书（≥2 份）或说"评审/筛选/对比" → 批量评审模式
- 其余情况 → 完整体检模式

## 三、L1 逻辑自洽层（知识体检主用）

### 变革理论(ToC)骨架
```
投入 → 活动 → 产出 → 成果(短期→中期→长期) → 影响
              ↑
          关键假设
```
- 断链 / 跳跃 / 伪因果 三类精确定位（指出发生在哪两个环节之间）。
- 区分"产出"（做了什么）与"成果"（改变了什么）。

### 四维体检
| 维度 | 检查要点 |
|------|---------|
| 逻辑链体检 | 断链（前后无连接）/ 跳跃（跨过中间环节直达远期影响）/ 伪因果（A、B 仅相关非因果） |
| 合一性校验（三A三力） | 驱动力(Aim)目标回应真实需求？行动力(Action)路径最有效？改变力(Action-effect)成果可归因？ |
| 假设风险筛查 | 列出显式/隐式假设，判 🟢靠谱/🟡存疑/🔴不靠谱；关键假设失效后果 |
| 受益方视角 | 成果从受益方定义？有参与/反馈渠道？是否考虑负面影响？ |

### 10 项快速自检（申报前/筹款前初筛）
1. 目标受益群体是否具体明确？
2. 项目目标是否可验证？
3. "产出"和"成果"是否区分？
4. 活动到成果是否有因果跳跃？
5. 核心假设是否写出（对照隐式假设模式库）？
6. 目标、方法、行动是否同向？
7. 成果声明是否有证据/合理推论？
8. 是否考虑"没有这个项目会怎样"（死重/替代渠道）？
9. 受益方是否有参与设计/反馈渠道？
10. 是否识别可能的负面影响？

> 计分口径：✅=1、⚠️=0.5、❌=0，满分 10。≥6 优先推进 / 3–5.5 补充复评 / <3 暂不推荐。

### 优先级与成熟度
- **P0 必须修复**：逻辑不成立（核心因果断裂、关键假设失效致命）。
- **P1 应该修复**：可做但效果打折（中间成果缺失、假设存疑）。
- **P2 建议优化**：锦上添花。
- 成熟度：⬜萌芽期（仅活动无成果）/ 🟦基础期（成果可描述未量化）/ 🟧进阶期（有量化体系）/ 🟩成熟期（可反事实归因）。

## 四、组织知识诊断用法（本技能衔接，L1）

把评估对象从"单个项目"扩展为"组织整体知识资产"：
1. 从 `evaluation` / `monitoring` 类抽 2–3 个代表项目，连同其 `proposal` 一起送检；
2. 跑 L1 完整体检，重点看 `proposal→implementation→monitoring→evaluation` 四类资料在知识库中是否闭环、有无断链/伪因果；
3. 上升到组织层：哪些知识区普遍薄弱、哪些披露项系统性缺失。

**输出物**：知识健康度卡片（各知识区完整度 + SIA 逻辑评级分布）+ 优化建议清单（P0/P1/P2，含验收标准）+ 知识管理建议（指定管理员、固定季度编译节奏、SIA 纳入结项必交件）。

> 若用户需要指标量化定级（L2）或价值核算（L3），告知这属于更高层级评估，完整框架见开源 `insigoo-sia`（MIT，github.com/ericyueric）；L1 报告可作为 L2/L3 的输入基础。
